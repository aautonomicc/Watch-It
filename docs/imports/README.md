# Import records

Files in this directory are provenance records for media proposed for the W@tch
library. They are source references, not downloaded media or Autonomi uploads.

A record marked public-candidate is ready to review in Add to W@tch, but it is
not public on the network. Before downloading or uploading, record the
creator's permission or a licence URL. After review, upload privately first;
publishing to a public channel remains a separate, permanent confirmation.

The first record is the Autonomi explainer video. Its YouTube URL is preserved
so the item can be handed to the desktop intake flow without losing attribution.
