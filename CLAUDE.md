# Watch-It

## Description
Cross-platform media player (Android, Android TV, iOS, Linux, Windows, macOS) for the Autonomi network. Client-only — no server side at all, and no Plex/Emby/Jellyfin server compatibility (stripped by design). Plex-style poster-wall UI.

## Tech Stack
Flutter 3.44.6 (SDK at ~/flutter) + media_kit (libmpv); SQLite via drift (media lists; codegen: `dart run build_runner build` in app/); Riverpod planned; Autonomi access via embedded Rust library `native/watchit_core` (ant-core, dart:ffi + in-process localhost streaming server) — no gateway/sidecar. `media_kit_video` is vendored at `app/third_party/media_kit_video` (pubspec dependency_overrides) carrying a Linux H/W-rendering patch — see Architecture Notes; drop when upstream fixes media-kit/media-kit#1404.

## Test Commands
In `app/`: `flutter analyze`, `flutter test` (PATH needs `~/flutter/bin`; `source ~/Android/env.sh` for Android builds). Live TMDB tests (test/tmdb_live_test.dart) need the credentials from the gitignored repo-root `.env`: `set -a; source ../.env; set +a; flutter test` — skipped automatically when TMDB_API_KEY is unset (CI needs no secrets). Dev build with the key bundled: `flutter run -d linux --dart-define-from-file=../.env` (dev/live-test only). Releases are KEYLESS since 2026-07-25 (user decision, reversing the alpha.24 bundling): release_build.sh no longer sources .env or passes any --dart-define, and `AppSettings.bundledTmdbApiKey` is deleted — users add their own key via Settings → Metadata (TmdbKeySource is now user|none). ⚠️ the old key IS extractable from published alpha.24–.33 binaries — rotate it on TMDB after the first keyless release ships. Release builds: run `scripts/release_build.sh` — it re-execs itself as transient systemd user unit `watchit-build` (survives session death; linger is on), builds APK then AppImage, logs to /tmp/watchit-build.log, refuses to double-launch. Follow with `tail -f /tmp/watchit-build.log`, status via `systemctl --user status watchit-build`; "ALL BUILDS DONE" in the log = success. Rust: `cargo test` in `native/watchit_core/` (needs `~/.cargo/bin` in PATH). Before `flutter build apk`: run `native/build-android.sh` (cargo-ndk → jniLibs). Host streaming harness: `cargo run --release --bin devserver` then curl `/health` and `/xor/<addr>`.

## Dev Server
`flutter run -d linux` in `app/` — Linux desktop toolchain installed (clang/ninja/libgtk-3-dev/libmpv-dev); Android also fully working. AppImage: `scripts/build_appimage.sh` (needs linuxdeploy at ~/tools/, output in dist/, gitignored).

## Architecture Notes
- Library = user-held **lists**; each entry is `{derived address, file name}` — DATAMAP-FIRST since alpha.40 (docs/PLAN-datamap-privacy.md): content enters ONLY via `.datamap` files (private `ant file upload` output, bare msgpack root DataMap; legacy ant-gui JSON sniffed by `{`) or `.watch-list` bundles; the address is blake3(rmp(shrink(root))) derived OFFLINE by `POST /datamap` (verify.rs::derive_address), == the public XOR address for public uploads (validated live against the real NOTLD map: POST of its 108KB datamap derives 66cacd06…cb13 exactly). Root map REQUIRED in the local mapstore; `/xor/{addr}` serves stored maps only and fast-fails 404 "data map missing — re-import" (no network resolve on the play path, kills the 20-31s cold resolve). Public XOR addresses REMOVED as entry type: no add-entry dialog (and since 2026-08-03 the list editor has NO add button at all — the Media page's "Add to library" is the single import entry point, which also creates lists), no plain-.txt import/export, no DataMapPrefetcher/prefetch dialogs/tile-open warm (all deleted; wiMessengerKey moved to widgets/messenger.dart). `GET /resolve/{addr}` is a LOCAL-store {size,chunks} lookup since alpha.41 (404 for never-imported; kept only for the download manager) — data_map_fetch, the v1 border conversion, library_migration.dart, and bundle-download-by-address were all deleted in alpha.41 (releases 2+3). Bundle spec v2 (docs/BUNDLE-FORMAT.md): `datamaps/<original filename>.datamap` members (zip root accepted — hand-made `zip lib.watch-list *.datamap` is valid), optional filename-line list.txt (`ListName=` + lines ending .datamap; hex lines = v1 → SKIPPED since alpha.41, all-v1 files error "re-export from 0.1.0-alpha.40+", rootmaps/ members ignored), unclaimed members → list named from bundle filename (prompt when network-fetched); export = bundle only from `GET /datamap/{addr}` (ant-cli-compatible msgpack), history checkbox kept, includeRootMaps/pre-resolve pass gone. Widget tests fake the embedded server via HttpOverrides (test/fake_embedded_http.dart — real sockets deadlock in the fake-async zone; XFile.fromData ignores `name:`, use `path:`)
- Lists live in SQLite via drift: lib/db/app_database.dart (tables media_lists/media_entries, position columns keep order; generated code checked in) behind the unchanged LibraryStore load/save/ensureDefaults API. media_lists.enabled (schema v3, default 1) drives per-list home-screen visibility; lists are managed on the dedicated Settings → Media Lists page (screens/media_lists_screen.dart: create, checkbox show/hide, rename/delete behind a 3-dot menu; tap opens ListEditScreen).
