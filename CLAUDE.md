# Watch-It

## Description
Cross-platform media player (Android, Android TV, iOS, Linux, Windows, macOS) for the Autonomi network. Client-only — no server side at all, and no Plex/Emby/Jellyfin server compatibility (stripped by design). Plex-style poster-wall UI.

## Tech Stack
Flutter 3.44.6 (SDK at ~/flutter) + media_kit (libmpv); SQLite via drift planned; Riverpod planned; Autonomi access via embedded Rust library `native/watchit_core` (ant-core, dart:ffi + in-process localhost streaming server) — no gateway/sidecar. `media_kit_video` is vendored at `app/third_party/media_kit_video` (pubspec dependency_overrides) carrying a Linux H/W-rendering patch — see Architecture Notes; drop when upstream fixes media-kit/media-kit#1404.

## Test Commands
In `app/`: `flutter analyze`, `flutter test` (PATH needs `~/flutter/bin`; `source ~/Android/env.sh` for Android builds). Rust: `cargo test` in `native/watchit_core/` (needs `~/.cargo/bin` in PATH). Before `flutter build apk`: run `native/build-android.sh` (cargo-ndk → jniLibs). Host streaming harness: `cargo run --release --bin devserver` then curl `/health` and `/xor/<addr>`.

## Dev Server
`flutter run -d linux` in `app/` — Linux desktop toolchain installed (clang/ninja/libgtk-3-dev/libmpv-dev); Android also fully working. AppImage: `scripts/build_appimage.sh` (needs linuxdeploy at ~/tools/, output in dist/, gitignored).

## Architecture Notes
- Library = user-held **lists**; each entry is `{XOR public file address, file name}`. Multiple lists; import/export; later publish/subscribe lists on Autonomi
- Metadata matcher parses file name → TMDB → artwork/description/category (same pipeline media servers use, but on-device); cached in SQLite
- Playback via libmpv (media_kit) everywhere; streams `http://127.0.0.1:<port>/xor/<addr>` from the embedded client — seek works via HTTP Range
- Linux H/W video rendering (alpha.17): vendored media_kit_video patch — upstream reads Flutter's EGL display with eglGetCurrentDisplay() on the platform thread, which returns EGL_NO_DISPLAY since Flutter 3.38, so every Linux box silently fell back to CPU mpv rendering + pixel-buffer copies (the Mint jerky-video/janky-spinner report). Patch defers the isolated-EGL-context + mpv_render_context creation to the first FlTextureGL populate on the raster thread, where Flutter's EGL display/context are current (EGLImage sharing is display-scoped, so it must be Flutter's own display — a fresh eglGetPlatformDisplayEXT display handle differs and eglMakeCurrent then fails EGL_BAD_ACCESS). Eager init retained when EGL is current on the platform thread (pre-3.38 embedders) so S/W fallback still works there. Files: linux/video_output.cc (video_output_ensure_hw_initialized), linux/texture_gl.cc, include/.../video_output.h
- Embedded client: `native/watchit_core` (Rust cdylib, ant-core pinned rev 629b87f) — tokio runtime + axum server on 127.0.0.1, `GET /xor/<addr>` (Range via self_encryption streaming_decrypt/get_range), `GET /health` for the Settings status tile; started once from main() over dart:ffi (lib/services/embedded_client.dart). APK is arm64-v8a only (abiFilters + jniLibs excludes); jniLibs/ and target/ are gitignored build artifacts
- Android $HOME shim (alpha.7): `watchit_core_start(peers_csv, data_dir)` — Dart resolves getApplicationSupportDirectory() in main() (awaited before runApp so no lazy start can race it) and the native side sets HOME/XDG_DATA_HOME/XDG_CONFIG_HOME to it before any ant-core code runs (temp-dir fallback when NULL). Needed because ant-core's config::data_dir unwraps the home-dir lookup → HomeDirNotFound panic on Android; peer cache persists in the app dir as a side benefit
- Connect hardening (alpha.6): each `Client::connect` attempt runs in its own task (panic→error) with 60s timeout; saorsa-core returns Ok with 0 peers when all bootstrap dials fail — engine treats that as failure; background retry loop 2s→60s backoff; `/health` while connecting = `{state, attempts, message}`; panics routed to tracing (logcat tag `watchit_core`). Devserver takes `WATCHIT_PEERS=ip:port` to test the failure path
- Download manager for offline: downloaded item = same entry with local path, full library UX offline
- Watch state/resume points local-only in SQLite; no accounts, no telemetry
- Branding follows the etchit.io family (fetch>it/etch/it): ink/bone/copper tokens, system fonts, mono for XOR addresses — see docs/BRAND.md (mirrors etchit-io/fetchit docs/BRAND.md)
- Repo: github.com/aautonomicc/Watch-It (MIT)
